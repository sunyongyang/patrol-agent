# Changelog

## [0.1.0.0] - 2026-10-14

### Added
- Export patrol PDFs for a single task or the latest run, with card selection for day, natural week, month, or a specific task.
- Restrict single-task and single-run report exports to the task creator.
- Add regression coverage for report routing, scope selection, ownership checks, date boundaries, and error paths.

### Changed
- Convert report and regression-test files to the repository's LF line-ending format.
- Update the patrol specification and interaction docs for report ranges and access scope.
